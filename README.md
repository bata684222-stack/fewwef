# WorkshopAG

Онлайн-воркшоп в стиле **AG — Armor Simulation**: регистрация/вход, TikTok-лента, посты с фото и JSON-чертежами, лайки/дизлайки, комменты, мой аккаунт, настройки.

База чистая — никаких демо-постов, только реальные люди.

## Локальный запуск

```bash
npm install
npm start
# открыть http://localhost:3000
```

## Что умеет фронт (`public/`)

- Первый экран — меню РЕГИСТРАЦИЯ / ВОЙТИ
- Лента (все / снаряды / постройки), поиск, сортировка новые/топ
- Реакции под постами: 🔥 👏 🎯 🧠 💀 (можно ставить несколько, повторный клик снимает)
- Клик по нику — профиль игрока: его посты, лайки, подписчики и кнопка «Подписаться»
- Галочки ролей рядом с ником: АДМИН (корона) · МОД (щит) · ✓ проверенный
- Просмотры: глазок со счётчиком под каждым постом, счётчик просмотров в профиле
- Группы: вкладка «Группы» в разделе форумов — создать, вступить, чат, кик, удалить
- Звонки: голос и видео 1-на-1 (WebRTC P2P) — кнопки в профиле и в шапке диалога, входящий звонок с мелодией; в настройках тумблер «Принимать звонки»

## Роли и модерация

**Админку получить самовольно нельзя — только выдача.** Правила такие:

- Самый первый зарегистрированный игрок становится админом автоматически (стартовый захват площадки).
- Дальше админа/модератора/галочку выдаёт только админ через панель.
- Ник владельца (`ADMIN_NAMES`, по умолчанию `xqzas`) зарезервирован: занять его или переименоваться в него нельзя, пока в базе есть хоть один админ.
- Владелец забирает права через `POST /api/setup {name, password}` со **своим** паролем — сработает, даже если ник уже занят кем-то другим. С чужим паролем — 401.
- Последнего администратора снять или удалить нельзя.
- Смена пароля убивает все старые токены.

Админка — кнопка **«Админка»** в профиле (видна только админам и модераторам):
- выдать/снять **админа**, **модератора**, **галочку** любому игроку (поиск по нику)
- удалить любой пост, комментарий, тему или ответ (корзина видна и у чужого контента)
- написать **объявление всем** — висит баннером у всех в ленте (модератор тоже может)
- удалить игрока со всем содержимым (только админ)
- статистика площадки

Обычные игроки удаляют только своё. Модератор не может выдавать админа и трогать игроков.

## Как игроки получают обнову

`index.html` отдаётся без кэша, а `app.js`/`style.css` — с версией-хэшем (`?v=...`), которая меняется при каждом деплое. Игрокам ничего делать не нужно, но если кто-то видит старьё — пусть нажмёт Ctrl+F5. Версия сборки видна в Настройках внизу и в `GET /api/health` (`version`), а также в заголовке `X-App-Version`.

## Бот

В разделе **ЛС** первым идёт **AG Бот** — отвечает на вопросы и считает статистику:

| Команда | Что делает |
|---|---|
| `/помощь` | список команд |
| `/стата` | посты, игроки, темы, комментарии |
| `/топ` | три лучших поста по лайкам |
| `/кто я` | твоя статистика |
| `/новости` | последнее объявление админа |
| `/модерация` | кому написать (админы и модераторы) |

Плюс понимает обычные фразы: «привет», «как дела», «спасибо», «кто ты» и вопросы про броню/снаряды.
- Новый пост: текст + фото (png/jpg/webp/gif, 5MB) + JSON-чертёж (проверяется, скачивается по ссылке)
- Лайк/дизлайк (один голос на акк), комменты, удаление своих
- Мой акк (аватар, мои посты), настройки (ник, пароль, аватар, удалить акк)

## API

- `POST /api/register`, `POST /api/login`, `GET /api/me`, `PATCH /api/me`, `DELETE /api/me`, `GET /api/me/posts`
- `GET /api/posts?kind=all|proj|build&q=&sort=new|top&limit=&offset=` (всего — в `X-Total-Count`)
- `POST /api/posts` (multipart: `title, body, kind, photo, jsonfile`), `DELETE /api/posts/:id`
- `POST /api/posts/:id/vote {value:1|-1|0}`
- `GET /api/reactions` → `['🔥','👏','🎯','🧠','💀']`
- `POST /api/posts/:id/react {emoji}` — переключает реакцию, возвращает пост с `reactions` и `myReactions`
- `GET/POST /api/posts/:id/comments`, `DELETE /api/comments/:id`
- `GET /api/health`
- Форумы: `GET /api/forums`, `GET /api/threads?cat=&sort=active|new&q=`, `POST /api/threads {cat,title,body}`, `GET /api/threads/:id`, `POST /api/threads/:id/replies {text}`, `DELETE /api/threads/:id`, `DELETE /api/treplies/:id`
- Личка: `GET /api/users?q=` (поиск акков), `GET /api/dm` (диалоги), `GET /api/dm/unread`, `GET/POST /api/dm/:uid`
- Профили: `GET /api/users/:id` (посты, лайки, подписчики, `follows`, счётчик просмотров), `POST /api/users/:id/follow` — переключить подписку
- Просмотры: `POST /api/posts/:id/view` (+1 к посту; просмотры чужого профиля растут сами при открытии)
- Рассылка: `GET /api/broadcasts` — последние 10 объявлений
- Админка: `GET /api/admin/stats`, `GET /api/admin/users?q=`, `POST /api/admin/user/:id/role {admin,mod,verified}`, `DELETE /api/admin/user/:id`, `POST /api/admin/broadcast {text}`, `DELETE /api/admin/broadcast/:id`, `DELETE /api/admin/{post|comment|thread|reply}/:id`
- Бот: `POST /api/bot {text}` → `{ reply }`
- Группы: `GET /api/groups?mine=&q=`, `POST /api/groups {name,desc}`, `GET /api/groups/:id` (участники), `POST /api/groups/:id/{join,leave}`, `POST /api/groups/:id/kick {userId}`, `DELETE /api/groups/:id`, `GET/POST /api/groups/:id/msgs`, `DELETE /api/groups/:gid/msgs/:mid`
- Звонки: `POST /api/calls {to,kind,offer}`, `GET /api/calls/incoming`, `GET /api/calls/:id/state`, `POST /api/calls/:id/{answer,ice,reject,hangup}`. Запрет звонков: `PATCH /api/me {callsOff:true}`. Медиа идёт напрямую между игроками, нужен белый IP хотя бы с одной стороны (без TURN за строгим NAT может не соединить)

## Деплой (Node 18+, `npm install`, старт `npm start`)

Обязательна переменная окружения **`JWT_SECRET`** (длинная случайная строка) — без неё в production сервер не стартует. Опционально: `PORT`, `CORS_ORIGIN`, `TRUST_PROXY`, `NODE_ENV=production`.

### Сохранение данных

Диск контейнера обнуляется при каждом деплое, поэтому без базы всё пропадёт. Приложение само выбирает хранилище, перебирая варианты по очереди:

| Что нашлось в переменных окружения | Что подхватится | Комментарий |
|---|---|---|
| `DATABASE_URL`, `POSTGRES_URL`, `POSTGRESQL_URL`, `PG_URL`, `DB_URL`, `DATABASE_URI` | **PostgreSQL** | аккаунты, посты, форумы, ЛС **и** фото/чертежи |
| `POSTGRES_HOST`/`PGHOST` (+ `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`) | PostgreSQL | строка собирается автоматически |
| `REDIS_URL`, `KV_URL`, `REDIS_URL_1`, `VALKEY_URL`, `REDIS_HOST` | Key Value | то же самое |
| `DATA_DIR`, `PERSIST_DIR`, `VOLUME_DIR` | постоянный том | база и файлы в этой папке |
| ничего | `data/db.json` + `public/uploads` | только для локальной разработки |

**RelaxDev:** в панели проекта → вкладка «База данных» → **«Создать базу данных»** (PostgreSQL 17). Платформа сама добавит `DATABASE_URL` в переменные окружения, код подхватит его без настройки. После этого сделай редеплой.

У внутренней БД RelaxDev **нет TLS** — это уже учтено: `sslmode/ssl/channel_binding` вырезаются из строки подключения, SSL отключается. Если у другого провайдера TLS нужен — поставь `DATABASE_SSL=true`. Для PgBouncer: `DATABASE_PGBOUNCER=true`. Размер пула: `DATABASE_POOL=5` (по умолчанию).

Если хранилище недоступно, сервер не падает: пишет в лог предупреждение и продолжает на диске (данные переживут рестарт процесса, но не деплой).

Проверить, что подхватилось: `GET /api/health` → `storage: { kind, source, mount }`. В логах строка `хранилище: pg (DATABASE_URL) ✓ переживает деплой`.

При первом запуске с базой приложение само переносит в неё локальный `data/db.json` и уже загруженные файлы — ничего не теряется.

Опционально: `DATABASE_SSL=false` если провайдер требует sslmode=disable.

### Бэкап

Весь массив данных хранится одной записью, поэтому его легко выгрузить: сама база — обычная таблица `ag_state` (колонка `data`, jsonb) и `ag_files`. Копия = `SELECT data FROM ag_state`; восстановление = вставить обратно.

Загрузки: `public/uploads/` (в `.gitignore`, файлы не коммитятся).

## Связка с игрой

В `index.html` воркшоп ходит на `wsBase`. После деплоя поставь URL WorkshopAG в игру как `wsBase`.
